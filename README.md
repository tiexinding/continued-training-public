# Continued Training

Data and code accompanying papers on continued (multi-stage) training of language models. Each paper has its own
self-contained directory.

| directory | paper |
|---|---|
| [`optimizer_history/`](optimizer_history/) | Tiexin Ding. *How AdamW's Second-Moment History Shapes Update Allocation After a Task Switch.* arXiv identifier to be added. |

The row and column scale-field analysis that this work builds on is described in Tiexin Ding, *A Mesoscopic View of
Transformer Weights Through Row and Column Scale Fields*, arXiv:2609.35852; its code is in
[NPM-Weibull-public](https://github.com/tiexinding/NPM-Weibull-public) (`scale_field/`).
